# 计算器前端（calculator-frontend）

软件工程第一次作业 —— 前后端分离计算器系统的**前端**部分。
原生 HTML / CSS / JavaScript，无任何框架、无构建工具。
前端只负责输入与展示，**所有计算、校验、历史存取都由后端完成**。

## 一、技术栈

- HTML5 + CSS3（Grid 布局、CSS 变量）
- 原生 JavaScript（ES2020+，使用 `fetch` 调用后端 API）
- 零依赖、零构建

## 二、运行方式

### 方式一：本地小服务器（推荐）

```bat
node serve.js          rem 默认 3000 端口；node serve.js 8081 可换端口
```

浏览器访问 http://localhost:3000

### 方式二：直接打开

双击 `index.html` 即可（后端已开启 CORS，file:// 方式同样能调通接口）。

### 方式三：静态托管

把整个文件夹上传到 Vercel / Netlify / GitHub Pages 即可（部署后记得改 `API_BASE`）。

## 三、配置说明

后端地址集中定义在 `js/app.js` 顶部，只需改这一行：

```js
const API_BASE = "http://localhost:8080/api";
```

- 本地联调：保持默认（后端跑在 8080）
- 部署到服务器：改成 `http://你的服务器IP:8080/api`

## 四、与后端连接的步骤

1. 先启动后端（见后端仓库 README），确认访问 `http://localhost:8080/api/history` 能返回 JSON；
2. 再按上面的方式启动前端；
3. 打开页面，顶部显示 **"● 后端已连接"** 即联通成功；
4. 显示 "● 后端未连接" 时请检查后端是否启动、端口是否一致。

## 五、功能清单

- 四则运算 / 运算优先级 / 括号 / 一元正负号 / 小数（均由后端计算）
- 非法表达式、除零等错误信息展示（后端返回原因，前端红色提示）
- 计算历史列表（来自后端数据库，页面刷新不丢失）
- 删除指定历史 / 清空全部历史
- 键盘输入支持：数字、`+ - * / ( ) .`、Enter = 计算、Backspace = 退格、Esc = 清空

## 六、目录结构

```
calculator-frontend
├── index.html      页面结构：计算器 + 历史面板
├── css/style.css   样式：两栏布局、按键网格、错误高亮
├── js/app.js       逻辑：输入收集、fetch 调后端、历史渲染/删除
└── serve.js        本地静态预览小服务器（可选）
```
